Industrial computer vision is rapidly transitioning from traditional rule-based image processing to **deep learning-driven visual anomaly detection**, **few-shot/zero-shot learning**, and **edge-accelerated quality control**.

**Key Market Context:**

## 🔓 Open-Source GitHub Projects 🌐

*Sorted by GitHub Stars Count (Descending)* 🌟

- **[Transformers](https://github.com/huggingface/transformers)** [![Stars](https://img.shields.io/github/stars/huggingface/transformers?style=social&color=white)](https://github.com/huggingface/transformers/stargazers)  
  **State-of-the-art Machine Learning for PyTorch, TensorFlow, and JAX**, Apache-2.0 licensed. Contains vision transformers (ViT, Swin, DINOv2) widely used for feature extraction in visual anomaly detection and industrial defect classification. 🤖

- **[OpenCV](https://github.com/opencv/opencv)** [![Stars](https://img.shields.io/github/stars/opencv/opencv?style=social&color=white)](https://github.com/opencv/opencv/stargazers)  
  **Open Source Computer Vision Library**, Apache-2.0 licensed. The foundational real-time computer vision and image processing library used for surface defect filtering, contour analysis, and preprocessing in manufacturing inspection systems. 👁️

- **[Ultralytics YOLO](https://github.com/ultralytics/ultralytics)** [![Stars](https://img.shields.io/github/stars/ultralytics/ultralytics?style=social&color=white)](https://github.com/ultralytics/ultralytics/stargazers)  
  **NEW - YOLOv8 / YOLO11 for Computer Vision Tasks**, AGPL-3.0 licensed. High-speed object detection, instance segmentation, and surface defect detection model suite optimized for edge performance and industrial inspection lines. ⚡

- **[Supervision](https://github.com/roboflow/supervision)** [![Stars](https://img.shields.io/github/stars/roboflow/supervision?style=social&color=white)](https://github.com/roboflow/supervision/stargazers)  
  **We write your reusable computer vision tools**, MIT licensed. Utility library by Roboflow for dataset management, detection annotators, zone monitoring, and tracking in visual quality inspection workflows. 🛠️

- **[FAISS (Meta AI)](https://github.com/facebookresearch/faiss)** [![Stars](https://img.shields.io/github/stars/facebookresearch/faiss?style=social&color=white)](https://github.com/facebookresearch/faiss/stargazers)  
  **A library for efficient similarity search and clustering of dense vectors**, MIT licensed. The core memory indexing engine underlying state-of-the-art anomaly detection algorithms such as PatchCore and PaDiM. 🔍

- **[MMDetection](https://github.com/open-mmlab/mmdetection)** [![Stars](https://img.shields.io/github/stars/open-mmlab/mmdetection?style=social&color=white)](https://github.com/open-mmlab/mmdetection/stargazers)  
  **OpenMMLab Detection Toolbox and Benchmark**, Apache-2.0 licensed. Comprehensive object detection and defect localization framework supporting dozens of vision backbones and inspection architectures. 📦

- **[OpenVINO Toolkit](https://github.com/openvinotoolkit/openvino)** [![Stars](https://img.shields.io/github/stars/openvinotoolkit/openvino?style=social&color=white)](https://github.com/openvinotoolkit/openvino/stargazers)  
  **Intel's toolkit for optimizing and deploying AI inference**, Apache-2.0 licensed. Accelerates deep learning visual inspection and anomaly detection models across Intel CPUs, GPUs, and VPUs at the industrial edge. 💻

- **[Anomalib (Intel)](https://github.com/openvinotoolkit/anomalib)** [![Stars](https://img.shields.io/github/stars/openvinotoolkit/anomalib?style=social&color=white)](https://github.com/openvinotoolkit/anomalib/stargazers)  
  **The leading open-source anomaly detection library**, Apache-2.0 licensed. Features **20+ algorithms** (PatchCore, PaDiM, FastFlow, Reverse Distillation, DRAEM), benchmark evaluation on MVTec AD/VisA, and OpenVINO edge deployment optimization. 🏭

- **[PatchCore](https://github.com/amazon-science/patchcore-inspection)** [![Stars](https://img.shields.io/github/stars/amazon-science/patchcore-inspection?style=social&color=white)](https://github.com/amazon-science/patchcore-inspection/stargazers)  
  **Towards Total Recall in Industrial Anomaly Detection (CVPR 2022)**, Apache-2.0 licensed. Memory-bank based anomaly detection framework achieving 99.1% AUROC on MVTec AD using only normal training images. 🎯

- **[PaDiM](https://github.com/xiahaifeng1995/PaDiM-Anomaly-Detection-Localization-master)** [![Stars](https://img.shields.io/github/stars/xiahaifeng1995/PaDiM-Anomaly-Detection-Localization-master?style=social&color=white)](https://github.com/xiahaifeng1995/PaDiM-Anomaly-Detection-Localization-master/stargazers)  
  **Patch Distribution Modeling Framework for Anomaly Detection**, open-source. Lightweight framework for anomaly localization without training parameters, ideal for fast industrial CPU inference. 📐

- **[Spot-Diff / VisA Benchmark](https://github.com/amazon-science/spot-diff)** [![Stars](https://img.shields.io/github/stars/amazon-science/spot-diff?style=social&color=white)](https://github.com/amazon-science/spot-diff/stargazers)  
  **Visual Anomaly and Novelty Detection Dataset (VisA) implementation**, Apache-2.0 licensed. Amazon Science project for spot-difference learning and high-resolution industrial anomaly detection benchmarking. 🔬

## ⚠️ Disclaimer ℹ️

- This is a **community-curated** list — not exhaustive and not an endorsement. ℹ️
- **Amazon Lookout for Vision reached End of Support on October 31, 2025** — existing customers must migrate to alternative anomaly detection solutions. AWS recommends custom SageMaker or self-hosted OpenVINO/Anomalib pipelines.
- **Anomalib is the leading open-source anomaly detection library** — featuring 20+ algorithms, MVTec AD benchmarking, and OpenVINO optimization for edge deployment.
- **Open-source visual inspection tools (Anomalib, PatchCore, PaDiM) are not turnkey** — they require labeled normal images for training, GPU resources, and integration with camera/lighting hardware. Always validate model accuracy on your specific defect types before production deployment. 🔍
